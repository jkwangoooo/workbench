# 阶段2实施契约：8班分组表与座次表

状态：本地实现与未应用 SQL；不连接远程 Supabase。

## 固定模板

- 分组模板版本 `1`：首行表头 `组别,成员1,成员2,成员3,成员4,组长`。成员列可扩展但必须在登记版本中明确；空字符串代表空位。
- 座次模板版本 `1`：首行元数据 `模板版本,1`，第二行 `行数,8,列数,9`，其后每个单元格为 `STUDENT:姓名`、`EMPTY`、`AISLE` 或 `PODIUM` 标记。第一行是逐格 `PODIUM`，后七行第5列为 `AISLE`，两侧为 `STUDENT:` 座位区，合计56个可填写座位；固定结构不依赖颜色或合并单元格。
- 解析器只接受登记版本、固定列数/行列数和精确标记；未知版本、额外结构或非法坐标拒绝。

## 数据映射与隔离

分组只生成 `GroupLayoutPreview`，保存时调用 `replace_group_layout`；座次只生成 `SeatingLayoutPreview`，保存时调用 `replace_seating_layout`。两者各自拥有上传状态、错误清单、repository、数据库表和打印模型。学生仅通过 `id/classId/displayName/sortOrder/active` 目录解析，禁止读取档案字段。

确认前仅保留内存中的结构化预览；确认或取消后释放预览与 `File` 引用。浏览器不执行先删后插，数据库函数在单一事务中替换并在失败时保留旧布局。

## 验收标准

- 入口只出现在“2025级8班班级管理”的分组表/座次表标签。
- 未登录不返回模板预览或学生姓名；7班不参与查询。
