# 备课工作流接口实施文档

> 状态：需求已确认，等待实施  
> 一级模块：备课工作流入口  
> 接入方式：独立网页，新浏览器标签页打开  
> 本文不包含：备课网页内部业务、备课数据库、统一登录、iframe嵌入、跨系统数据同步

## 1. 文档目的

本文件定义教师工作台与独立备课网页之间的最小接入契约。工作台只负责展示入口和执行跳转，不复制、读取或修改备课网页的业务数据。

备课系统继续独立维护和部署。工作台的学生、成绩、反馈、课表、待办和资源库模块不得依赖备课网页可用性，也不得向备课网页传递数据。

## 2. 页面与入口

- 工作台始终显示“备课工作流”入口。
- 入口状态由部署配置决定：
  - 配置有效的 `https://` 地址：入口可点击。
  - 地址为空、格式非法或不符合生产环境协议：入口置灰，显示“尚未配置”。
- 点击有效入口时，在新的浏览器标签页打开独立备课网页。
- 工作台当前页面保持不变，用户填写中的工作台内容不因跳转被清空。
- 不使用 iframe、弹窗内嵌或工作台内部路由承载备课网页。

## 3. 配置契约

### 3.1 配置项

使用部署环境变量配置地址：

```text
PREP_WORKFLOW_URL=https://your-prep-workflow.example.com
```

- 配置只在部署环境或部署配置中修改。
- 普通使用者不能在网页设置中编辑该地址。
- 配置缺失时按“尚未配置”处理，不使用硬编码备用地址。

### 3.2 地址校验

生产环境只允许绝对 `https://` URL：

- 必须使用 `https:` 协议。
- 必须存在合法主机名。
- 不接受 `javascript:`、`data:`、相对路径或任意 `http://` 地址。
- 不把查询参数、token、学生ID、成绩或其他工作台数据拼接到目标地址。
- 校验失败时不执行打开操作，并显示“尚未配置”。

开发环境如需访问本机备课网页，应通过单独的开发配置和明确的环境判断处理；生产构建不得放宽为任意HTTP地址。

## 4. 打开与失败行为

- 使用安全的新标签页打开方式，并保留原工作台页面。
- 浏览器阻止新标签页时，显示明确提示，不改变入口状态。
- 目标网页暂时不可用时，工作台只显示跳转已发起；不尝试代理、抓取或缓存备课网页内容。
- 工作台不轮询备课网页健康状态，不因备课网页离线而阻塞其他模块。
- 入口打开失败不写入任何工作台业务表。

## 5. 数据与权限隔离

- 工作台不保存备课网页内容、页面状态、登录凭据或会话令牌。
- 不向目标地址发送工作台用户信息、学生信息、成绩、反馈、课表、待办或资源库文件路径。
- 不从目标网页读取数据，不建立跨域 `postMessage` 数据协议。
- 备课网页的认证、权限、数据存储和隐私策略由备课系统自行负责。
- 工作台入口配置属于应用配置，不作为学生或教学业务数据写入数据库。

## 6. 代码结构与接口边界

```text
src/modules/prep-workflow/
  domain/
    prepWorkflowConfig.ts
    prepWorkflowUrl.ts
  components/
    PrepWorkflowEntry
  index.ts
```

边界规则：

- `prep-workflow` 只依赖通用UI和配置读取能力，不依赖学生、成绩、反馈、课表、待办或资源库 repository。
- 页面组件不得直接读取任意环境变量并自行拼接跳转逻辑；统一通过 `prepWorkflowConfig` 和 `prepWorkflowUrl` 获得经过校验的目标。
- URL校验使用纯函数，便于测试空值、非法协议、缺少主机名和合法HTTPS地址。
- 入口组件只接收“有效目标”或“尚未配置”状态，不接收学生或其他业务对象。

## 7. 实施顺序

1. 建立备课工作流入口模块目录和配置类型。
2. 实现生产环境 `https://` URL校验。
3. 实现未配置/无效配置时的置灰入口和提示文本。
4. 实现有效配置在新标签页打开的跳转行为。
5. 加入配置缺失、非法URL、浏览器阻止打开和有效跳转测试。
6. 验证备课入口不可读取或写入其他工作台模块数据。

不得在本模块实施时顺带修改独立备课网页、统一登录、学生档案、成绩、反馈、课表、待办或资源库。

## 8. 验收标准

- 工作台始终显示“备课工作流”入口。
- 没有配置地址时入口置灰并显示“尚未配置”，点击不打开页面。
- 非HTTPS、空值、相对路径和非法URL均被拒绝。
- 有效HTTPS地址点击后在新标签页打开，原工作台页面保留。
- 跳转不会携带学生、成绩、反馈、课表、待办或资源库信息。
- 入口不可用或目标网页离线时，工作台其他模块仍可正常使用。
- 工作台不保存备课网页内容、登录凭据或会话令牌。
- 配置或跳转失败不会产生业务数据库写入。

## 9. 暂不实施

- iframe嵌入备课网页
- 工作台与备课系统统一登录
- 跨系统 `postMessage` 数据交互
- 学生、成绩、反馈、课表、待办或资源库数据传递
- 备课网页内容同步、缓存或代理
- 备课网页健康监控和离线镜像
